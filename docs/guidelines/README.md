# ガイドライン索引

レビューの指摘などから得た、条件付きで再利用できるルールの索引。
作り方・状態・承認の正本は [knowledge.md](../process/knowledge.md)、記入様式は [テンプレート](../templates/guideline.md)。

- 作業の開始時は、この表の「区分」「適用範囲」「参照する場面」を見て、当たるものだけを読む。区分が `全般` のものを上に並べる（[knowledge.md §5](../process/knowledge.md#5-索引への登録と活用の確認)）。
- `proposed` は参考として読む。違反しても完了の阻害にはしない。`active` には従う。`deprecated` は新しい作業では使わない。

| ID | 要点 | 状態 | 区分 | 範囲 | 適用範囲 | 参照する場面 | 確認方法 |
|---|---|---|---|---|---|---|---|
| [GL-001](GL-001-keep-always-read-docs-small.md) | 作業のたびに読む文書には、そのとき必要な情報だけを置き、履歴や経緯は別のファイルに分ける | `proposed` | 全般 | 汎用 | 入口・索引・README など、作業の開始時に読む文書 | 常に読む文書に記述を足すとき | レビューで、常に読む文書に履歴・経緯が足されていないかを見る |
| [GL-002](GL-002-requests-to-humans.md) | 人間への依頼は、目的を結論から書き、対象ごとに分け、指している対象と答え方の分かる問いを書き、見てほしい内容だけにする | `proposed` | レビュー | 汎用 | レビュー依頼、承認の依頼、報告など、人間に判断を求める文章 | 人間に依頼や報告を書くとき | 各依頼に対象と問いと確かめた結果があり、経緯や長い引用がないかを見る |
